# Guide interactif d’Istanbul

Carte mobile des dix principaux quartiers touristiques depuis le Mövenpick Istanbul Old Town.

## Lancer localement

Servir ce dossier avec un serveur HTTP statique. La carte nécessite une connexion Internet pour charger Leaflet et les tuiles OpenStreetMap.

## Publication

Le site est prévu pour GitHub Pages à la racine de la branche publiée.

## Mise à jour des prix

Les prix et taux de change ont été vérifiés le 27 octobre 2026. Mettre à jour `app.js` et la date affichée dans `index.html` avant un voyage ultérieur.
